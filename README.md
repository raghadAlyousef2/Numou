# Numou – Graduation Project

## Overview
Numou is an AI-based Android educational application designed to help Arabic-speaking children aged 3–7 learn Arabic letters and words in an interactive and engaging way.

This project was developed as our **Graduation Project** at King Saud University.

## Features
- Arabic letters and vocabulary learning
- Interactive letter tracing
- Pronunciation practice
- Progress-based quizzes
- Points and achievement badges
- Parent dashboard to track learning progress

## AI Technologies
- **Google Speech Recognition** for pronunciation practice
- **OCR** for recognizing handwritten letters during tracing activities
